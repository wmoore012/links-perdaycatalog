# LinkTree — React + TypeScript

Modern mobile-first LinkTree built with Vite, React, TypeScript and Framer Motion.

Quick start:

```bash
# install deps
npm install

# dev server
npm run dev

# build for production
npm run build
```

Notes:
- This is a single-file LinkTree app in `src/App.tsx` — edit the `LINKS` array to change links.
- Designed for mobile-first display; microanimations are implemented with `framer-motion`.
